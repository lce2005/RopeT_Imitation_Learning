# GitHub 업로드

이 `RopeT_Portfolio` 폴더만 새 저장소로 올립니다. 원본 수업 저장소의 `.git` 이력과 원격 주소는 복사하지 않았습니다.

GitHub에서 빈 저장소를 만든 다음 이 폴더의 Anaconda Prompt에서 YOUR_USERNAME을 바꿔 실행하세요.

```bat
git init
git branch -M main
git add .
git status --short
git commit -m "Add Rope-T imitation learning portfolio"
git remote add origin https://github.com/YOUR_USERNAME/rope-t-imitation-learning.git
git push -u origin main
```

시연·가중치·영상·실행 출력물은 `.gitignore`로 제외합니다. 영상 공개 범위를 확인해 별도 공유 링크를 README에 추가할 수 있습니다. 제공 코드·데이터와 공동 작업물의 공개 범위는 수업 정책과 출처 권한을 따릅니다. 상세 기여와 출처는 `ATTRIBUTION.md`에 있습니다. 실제 업로드는 수행하지 않았습니다.
