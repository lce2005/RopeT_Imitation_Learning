# 모델 학습과 실험 과정

## 문제와 구현

사람이 로프를 막대로 밀어 목표 T 모양에 맞추는 행동을 학습합니다. 개인 담당은 M3 모델 학습입니다.

- `dataset.py`: 상대 위치 중심의 77차원 특징, 관측·행동 창, 정규화와 학습 데이터 구성.
- `policy.py`: 256×3 은닉층과 GELU를 사용하는 MLP, 관측 이력 관리와 행동 복원.
- `train_bc.py`: 표준화 행동의 MSE를 최소화하고 검증 손실이 가장 낮은 모델을 저장.
- `train_rl.py`: BC 정책을 PPO로 미세조정하고, BC 행동에서의 이탈을 제한하는 손실 추가.

각 파일에는 제공받은 인터페이스와 헬퍼 코드도 포함됩니다. 시연 수집과 최종 평가는 팀 공동 작업입니다.

## 비교와 판단

73개 선별 시연과 행동 창 1을 사용한 비교에서 관측 창 1은 52%, 2는 82%, 4는 44%의 최종 성공률을 보였습니다. 이전·현재 관측을 함께 사용하면 변화 정보를 활용할 수 있다는 해석이 가능합니다. 다만 관측 창이 더 길다고 항상 좋아지지는 않았습니다. 데이터 규모, 입력 차원과 최적화의 영향은 분리해서 검증하지 않았습니다.

BC+PPO는 한 번 이상 성공한 비율을 88%에서 90%로 높였지만 최종 성공률은 82%로 같았습니다. 성공 후 마지막에 실패한 에피소드는 3개에서 4개로 늘었고, 최종 모양 오차 중앙값도 3.85mm에서 6.50mm로 커졌습니다. 따라서 일시적 성공과 마지막 시점 성공을 구분하고 최종 모델을 obs2 BC로 유지했습니다.

## 한계와 다음 실험

단일 학습 시드와 공통 평가 시작 상태 50개의 결과입니다. 반복 학습 시드에 대한 분산은 측정하지 않았습니다. 이후 성공 유지 행동, 변화량 특징, 시연 품질을 통제한 비교를 검토할 수 있습니다. 이는 향후 후보이며 확인된 개선 결과가 아닙니다.
